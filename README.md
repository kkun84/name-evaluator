# 至福の命名大吉診断

入力したお名前の画数を数え、壮大なスロットマシン風アニメーションと共に大吉のメッセージを贈る静的サイトです。GitHub Pages などの静的ホスティングにそのまま配置できます。

## 利用方法

1. `index.html` をブラウザで開きます。
2. フォームにお名前を入力して診断ボタンを押すと、画数の内訳と大吉メッセージが表示されます。

## 開発メモ

- 主要なスタイルは `assets/styles/main.css` にまとめています。
- JavaScript は ES Modules を用い、`assets/scripts` 以下で役割ごとに分割しています。
- 画数データは `assets/data/strokeData.js` に含まれており、未登録の文字は自動的に推定されます。
